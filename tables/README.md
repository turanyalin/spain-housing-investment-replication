# Spain reference tables

These files are generated by the national Spain pipeline, retained alongside the main EU panel. Run `python reproduce.py` for both analyses, or the three entry points in the [Spain guide](../replication/README.md).

| File | Contents |
| --- | --- |
| `descriptive_table.tex` | Spain descriptive statistics |
| `main_models_table.tex` | Four national OLS/HAC models; included in the main paper as the Spain benchmark table |
| `sensitivity_table.tex` | Nine national sensitivity specifications |
| `diagnostics_table.tex` | Spain ADF diagnostics |

The main EU empirical tables, coverage, and numerical-text macros are generated in `panel/output/`. The source and literature tables remain in `main.tex`. Edit the analysis or templates and regenerate rather than editing numerical table files by hand.
